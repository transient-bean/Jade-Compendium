# Jade Compendium — Skill Archive & Build Calculator

An authentic, skeuomorphic skill planner and character database for **Jade Dynasty (Patch 3.11)**.

## Features
- **12 Playable Classes**: Full skill trees and Tome books across Human and Athan factions (including Jadeon, Vim, Skysong, Lupin, Modo, Incense Mage, Arden, Balo, Rayan, Celan, Forta, and Voida).
- **Authentic Xianxia Aesthetics**: High-fidelity 2008–2011 Jade Dynasty PC client UI, gilded borders, celadon jade accents, and classic backdrop vignettes.
- **6-Axis Combat Radar & Heatmap**: Canonical 3.11 capability matrix with dynamic color coding (**Red** `< 50`, **Amber** `50–74`, **Green** `≥ 75`).
- **Interactive Tome Synergies**: Live cross-tree highlights and deep links showing exact relationships between Faction Skills and Tomes.
- **Local Browser Persistence**: All builds and characters automatically save to browser `localStorage`.
- **URL Build Sharing**: Share complete character allocations with a single click.

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
